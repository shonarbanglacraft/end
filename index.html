SBC

On 20 May, I decided to close the Minecraft server.

I originally opened this server just to explore how Minecraft servers work and honestly... it became an amazing learning experience for me. I built almost the entire server with the help of AI, learned plugins, setup, VPS management, optimization, configs, permissions, worlds, discord bots and so many things I never knew before.

Even though the server never became very active and it still needed a lot of optimization, the excitement of building and running my own server was worth every single moment.

Thank you to everyone who joined, tested, explored, and supported the server, even for a short time.
